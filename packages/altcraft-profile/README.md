# Altcraft React Native SDK — Profile

![Altcraft SDK Logo](https://guides.altcraft.com/img/logo.svg) [![React Native](https://img.shields.io/badge/React_Native-0.75%2B-blue?style=flat-square)](https://reactnative.dev/) [![Platforms](https://img.shields.io/badge/Platforms-Android_iOS-green?style=flat-square)](#) [![npm](https://img.shields.io/npm/v/@altcraft/profile.svg?style=flat-square)](https://www.npmjs.com/package/@altcraft/profile)

Altcraft React Native SDK is a library for interacting with the **Altcraft Marketing Platform**. The **Profile** package is one of its modular components.

---

## Profile

The Profile module is responsible for user profile fields.

- [x] Updating profile fields from the app.
- [x] Native event message catalog (`moduleEvents`).

---

## Dependencies

Add the **Profile** package, Core, and Push to your React Native application:

```sh
npm install @altcraft/profile @altcraft/core @altcraft/push
```

---

## Requirements

- React Native 0.75+ (tested with 0.81.1).
- Android 7.1+ (API 25).
- iOS 13.0+.
